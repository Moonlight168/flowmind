# AI 设计能力支持矩阵

本文档描述 FlowMind 当前版本通过自然语言生成或修改设计的实际能力。这里的“支持”表示 AI 输出、结构化协议、转换、校验和前端应用已经形成完整链路；设计器中可以手动配置，不等于 AI 已支持生成。

状态说明：

- **支持**：可通过自然语言稳定生成或修改，并应用到设计器。
- **部分支持**：已有结构或底层格式可以承载，但生成、反解析、校验或回显链路尚未完全覆盖。
- **不支持**：AI 协议未开放，或当前不会把模型输出应用到设计器。

## 流程模型设计

### 图结构与节点

| 能力 | 状态 | 当前行为与边界 |
|---|---|---|
| 新建完整审批流程 | 支持 | 可生成开始事件、用户任务、网关、结束事件及连线，并生成 BPMN XML 和画布布局。 |
| 增加、修改、删除节点 | 支持 | 通过真实节点 ID 执行增量操作。 |
| 增加、修改、删除连线 | 支持 | 支持连线名称、默认分支及条件。 |
| 整体重新设计 | 支持 | 由模型根据用户意图和当前结构决定是否整体替换，不依赖固定关键词。 |
| 用户任务 `USER_TASK` | 支持 | 可配置表单、审批人、候选用户、候选角色、优先级和到期时间。 |
| 排他网关 `EXCLUSIVE_GATEWAY` | 支持 | 非默认出线支持 `eq/ne/gt/ge/lt/le` 条件，最多设置一条默认出线。 |
| 并行网关 `PARALLEL_GATEWAY` | 支持 | 支持并行分支和汇聚，不允许在并行出线上设置条件。 |
| 包容、复杂、事件网关 | 部分支持 | 结构化模型和 BPMN 生成器可以承载，但缺少与排他、并行网关同等级的业务校验和回归覆盖。 |
| 中间抛出事件 | 部分支持 | 可以生成普通中间抛出事件，尚不支持消息、信号、定时器等具体事件定义。 |
| 服务任务、脚本任务、手工任务、业务规则任务、发送/接收任务 | 不支持 | 现有流程中会尽量保留为不透明节点，但 AI 不能可靠新增或修改。 |
| 子流程、调用活动 | 不支持 | 当前结构化操作协议不支持嵌套流程内容。 |
| 边界事件、捕获事件、定时器、消息、信号、错误事件 | 不支持 | 尚未进入 AI 节点协议和确定性转换链路。 |
| 泳道、参与者、消息流 | 不支持 | 当前仅处理单一流程内的节点和顺序流。 |

### 用户任务配置

| 配置项 | 状态 | 当前行为与边界 |
|---|---|---|
| 绑定表单 | 支持 | 优先查询并复用高度相似的现有表单；没有合适表单且节点确实需要录入数据时，可生成新表单方案，经变更预览确认后创建和绑定。 |
| 指定审批人 | 支持 | 必须使用后端可验证的真实用户 ID；不会把显示名称直接写成 ID。 |
| 候选用户 | 支持 | 使用后端查询到的真实用户 ID。 |
| 候选角色 | 支持 | 使用后端查询到的真实角色 key，不编造 `ROLE1`、`ROLE2`。 |
| 发起人、表达式审批 | 支持 | 支持 `INITIATOR` 和有明确依据的 Flowable 表达式。 |
| 优先级、到期时间 | 部分支持 | 全量生成器可以写入 BPMN；当前自然语言生成和已有 XML 反解析的回归覆盖不足。 |
| 多实例 | 部分支持 | 可生成串行/并行、集合变量、元素变量和完成条件；不会在缺少变量依据时编造配置。已有高级配置的反解析和增量编辑仍需补齐。 |
| 任务监听器 | 部分支持 | 可以写入事件、类、委托表达式、表达式和固定字段；只有上下文提供真实实现信息时才应生成。当前没有监听器目录查询能力。 |
| 执行监听器 | 部分支持 | 生成能力与任务监听器相同，不能凭业务描述编造 Java 类名或表达式。 |
| 扩展属性 | 部分支持 | BPMN 可以承载键值属性；仅应生成系统已有明确约定的属性，当前没有扩展属性定义目录。 |
| 任务事件、监听器类型的任意组合 | 不支持 | 未建立完整枚举、兼容性校验和运行时验证，不能保证所有设计器选项都能由 AI 正确配置。 |

### 流程基础信息

| 配置项 | 状态 | 当前行为与边界 |
|---|---|---|
| 流程名称、标识、描述 | 支持 | 可以自然语言生成或修改。 |
| 流程分类 | 支持 | 使用后端已有分类；分类不存在时可提出创建方案并在应用变更时创建。 |
| 版本、部署状态、租户等运行信息 | 不支持 | 属于模型管理和部署阶段，不由 AI 设计直接生成。 |

## 表单设计

### 表单结构与字段

| 能力 | 状态 | 当前行为与边界 |
|---|---|---|
| 新建完整表单 | 支持 | 根据业务描述生成表单名称、字段、校验、选项和基础布局。 |
| 增加、修改、删除、移动字段 | 支持 | 使用字段真实 `options.name` 定位并执行增量修改。 |
| 整体重新设计 | 支持 | 模型根据意图决定是否整体替换。 |
| 输入框、文本域、富文本、数字、滑块 | 支持 | 可配置名称、标签、默认值、占位符、必填和组件特有参数。 |
| 单选、多选、下拉、级联 | 支持 | 必须生成非空选项；支持单选/多选等基础参数。 |
| 时间、时间范围、日期、日期范围 | 支持 | 支持格式、值格式和起止占位文字等基础参数。 |
| 开关、评分、颜色 | 支持 | 支持基础值和常用参数。 |
| 图片上传、文件上传 | 部分支持 | 可生成字段及文件类型、数量、大小等静态限制；上传地址、鉴权和上传事件不会由 AI 生成。 |
| 静态文本、HTML、按钮、分隔线、提示 | 部分支持 | 可以生成展示结构；按钮点击逻辑和任意 HTML 行为不生成。 |
| 栅格、卡片、标签页、表格布局 | 支持 | 支持嵌套字段和基础布局参数。 |
| 远程数据源、动态选项、接口联动 | 不支持 | 当前没有受控的数据源协议和接口选择能力。 |
| 字段联动、条件显隐、计算公式 | 不支持 | 当前事件与表达式链路未开放给 AI。 |

### 表单全局配置

| 配置项 | 状态 | 当前行为与边界 |
|---|---|---|
| 标签位置 `labelPosition` | 支持 | 可通过自然语言生成。 |
| 标签宽度 `labelWidth` | 支持 | 可通过自然语言生成。 |
| 数据对象名称 `modelName` | 支持 | 可通过自然语言生成。 |
| 引用名称 `refName` | 支持 | 可通过自然语言生成。 |
| 全局组件大小 `size` | 不支持 | 新生成表单使用默认值。 |
| 字段标签对齐 `labelAlign` | 不支持 | 新生成表单使用默认值。 |
| 验证规则名称 `rulesName` | 不支持 | 当前固定为 `rules`。 |
| 全局自定义类 `customClass` | 不支持 | AI 生成链路不会设置。 |
| 全局 CSS `cssCode` | 不支持 | 不接受模型生成的任意 CSS。 |
| 表单全局函数 `functions` | 不支持 | 不接受模型生成的任意 JavaScript。 |
| SFC 生成设置 | 不支持 | 属于设计器代码导出偏好，不在 AI 表单协议中。 |
| `onFormCreated`、`onFormMounted`、`onFormDataChange`、`onFormValidate` | 不支持 | 新生成表单使用空回调。 |

### 字段高级配置

| 配置项 | 状态 | 当前行为与边界 |
|---|---|---|
| 名称、标签、默认值、占位符 | 支持 | 按组件能力生成。 |
| 必填、禁用、只读、清空 | 支持 | 支持声明式字段状态。 |
| 长度、数值范围、精度、步长、行数 | 支持 | 仅对相应组件生效。 |
| 选项、日期时间格式、文件限制 | 支持 | 按组件类型生成和校验。 |
| 单字段标签宽度、标签对齐 | 不支持 | 新字段由转换器补默认值。 |
| 单字段自定义 CSS 类 | 不支持 | 新字段由转换器补空值；既有字段未被修改时会保留原配置。 |
| `onCreated`、`onMounted`、`onChange`、`onInput`、`onFocus`、`onBlur` 等事件 | 不支持 | 新字段事件统一为空，不执行模型生成的任意代码。 |
| 自定义校验函数 | 不支持 | 当前只生成受控的声明式校验参数。 |

## 安全边界

CSS、全局函数、生命周期回调和字段事件都可能包含可执行内容。当前版本有意不让模型直接生成并执行任意代码。后续若开放，应使用受控动作协议或白名单函数，并增加变更预览、语法校验、危险 API 检查和用户明确确认，而不是直接保存模型返回的 JavaScript。

已有表单或流程中手动配置的高级属性，在未被本次增量操作涉及时会尽量保留；“能够保留”不代表 AI 能够正确创建或修改这些属性。
