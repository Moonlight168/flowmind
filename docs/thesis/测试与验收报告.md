## 2. 可复核命令

在 `flowmind-cloud` 执行：

```powershell
mvn -pl ruoyi-modules/ruoyi-flowable,ruoyi-gateway -am test '-DfailIfNoTests=false' -B -q
```

在 `flowmind-ui` 执行：

```powershell
npm run test:run -- --maxWorkers=2 --minWorkers=1
npm run build:prod
```

真实模型评测使用 AI 子项目现有数据集脚本。执行前确认专用测试账号、数据集、模型预算；不要默认运行全部数据集。`FLOWMIND_AUTH_TOKEN` 与模型/Langfuse 密钥不出现在截图和报告中。
