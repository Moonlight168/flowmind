# FlowMind 毕业设计任务书与过程记录

> 通用内容草案。学生、学校、指导教师、起止日期及签字栏按学校模板填写。下列周次是建议计划，不代表已执行记录。

## 一、课题任务

设计并实现一套支持自然语言辅助建模的智能审批平台。系统应同时具备传统审批业务闭环和可控的 AI 设计能力，而非仅提供聊天页面。

主要任务：

1. 分析流程管理员、申请人、审批人和抄送接收人的需求与访问边界。
2. 实现分类、流程基本信息、动态表单、BPMN 模型四类设计入口。
3. 通过 LangGraph 编排需求理解、业务检索、结构化生成、校验与结果格式化。
4. 实现变更预览、用户确认应用、版本与未保存状态管理。
5. 对接 Flowable 的部署、发起、审批、签收、退回、撤回和历史查询。
6. 集成 Langfuse 追踪、四类数据集和内部实验触发入口，保留可复核的测试证据。
7. 完成部署说明、使用手册、测试报告、论文与答辩演示。

## 二、验收边界

- 生成结果应能进入真实设计器继续编辑；未经确认不得直接覆盖用户设计。
- 系统引用的表单、用户和角色应来自实际业务数据；生成意图与实际落库行为分离。
- 普通登录用户不应因掌握他人任务或实例 ID 而获得办理、读取或删除权限。
- 模型澄清、校验失败和外部服务不可用应有明确反馈，不伪造成功。
- 评测“状态与输出检查通过”不等于 BPMN 业务正确，需另外进行人工验收和实际流程执行。
- 不承诺本课题已解决所有 BPMN 元素、复杂串行会签临时改派、多租户和生产高可用问题。
