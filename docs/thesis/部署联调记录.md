## 操作命令

镜像拉取可能耗时较长，由操作者在终端执行：

```powershell
docker pull nginx:1.27-alpine
cd G:\flowmind\docker\flowmind
docker compose -f docker-compose.yml up -d --no-build
docker compose -f docker-compose.yml ps
```

以上不重新打包 Java。当前运行 Java 镜像仍是旧构建，不能据此宣称上一轮源码修复已部署；需要另行打包 JAR、按仓库构建流程更新镜像后再验收。

目标 webhook 地址为 `http://flowmind-webhook/webhooks/experiment`，只在共享 Docker 网络内使用。不得把“容器 Running”“AI healthy”或“HTTP 202”写成完整实验成功。

本记录不包含数据库直连操作、密钥、账号密码和真实业务内容。后续完成时补充实际响应状态、脱敏 trace/run 标识、执行时间及用例结果，不覆盖失败过程。
