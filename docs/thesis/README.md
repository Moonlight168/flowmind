# FlowMind 本科毕业设计材料

本目录以“基于大语言模型的智能流程审批系统设计与实现”为题整理材料。学校模板和指导教师要求优先；这里提供可修改的工程内容，不代替学校表格、导师签字和实际研究记录。

## 阅读与提交顺序

| 阶段 | 材料 | 本仓库内容 |
| --- | --- | --- |
| 选题、立项 | 任务书、进度计划 | [任务书与过程记录](任务书与过程记录.md)，任务与计划已起草，实际记录待填写 |
| 开题 | 背景、研究内容、技术路线 | [开题报告](FlowMind本科毕业设计开题报告.md) |
| 实现 | 需求、总体设计、关键实现 | [需求与设计说明](需求与设计说明.md)，配合源码阅读 |
| 测试 | 测试方案、执行证据、问题闭环 | [测试与验收报告](测试与验收报告.md)，区分已执行与待执行 |
| 交付 | 环境安装、用户操作、故障排查 | [部署与用户手册](部署与用户手册.md) |

## 通常还要向学校确认的材料

- 中期检查表、导师指导记录、周志：只记录真实日期、工作与反馈，不能补造签字或会议。
- 文献综述：可在论文绪论基础上整理，但需核验每条文献原文、作者、年份和引用位置。
- 外文原文与译文：仅在学校要求时提交，确认来源及使用权限，不把自动生成的文本当作原文。
- 答辩申请、查重报告、评阅意见、成绩评定表、原创性声明与授权书：使用学校正式系统或模板。
- AI 辅助使用声明：按学校要求说明 AI 用于哪些环节、哪些结论由本人验证。
- 源码归档、运行包、数据库结构与脱敏初始化数据：不交付真实账号、Token、密钥、业务记录或完整 `.env`。

## 定稿检查

1. 论文标题、开题、任务书与答辩 PPT 的课题名称一致。
2. 把 RuoYi-Cloud、Flowable、VForm3 等上游能力与本人完成的 AI 设计集成、校验、预览等工作分开说明。
3. 所有“已实现”“已验证”“性能提升”均可对应源码或测试证据；未测指标不得填写估计数字。
4. 不把 Langfuse 收到 trace、webhook 返回 202、实验跑完、模型生成正确混为一个结论。
5. 论文原有测试数量属于对应历史版本；最终提交前按实际交付提交重新测试、更新环境和结果。
6. 图表编号、正文引用、参考文献、学校封面与页码在导出 Word/PDF 后再次核对。
7. 个人信息、指导意见和签名由本人及指导教师填写。本目录的待填项不是已完成证明。

建议最终归档记录：提交 SHA、是否有未提交修改、操作系统、依赖版本、执行命令、测试日期、截图与报告路径。
