# 黄金数据集评估实施记录

## 目标

为 FlowMind 设计链路建立可版本化的黄金数据集，支持全量或按稳定用例 ID 执行，并将每条用例的输入、输出和确定性评分关联到 Langfuse Dataset Run。

## 设计

- 黄金数据集使用 JSONL 管理，每行一条独立用例，并由 Pydantic 校验结构。
- 用例覆盖流程设计、表单设计、分类设计、基本信息模式和澄清语义。
- 执行任务直接调用生产 `invoke_design_workflow`，避免评估链与真实业务链偏离。
- 评分只验证稳定契约：意图、必需路径、最小数量、节点类型、控件类型和错误兜底契约，不对模型自然语言做精确匹配。
- 每条评估使用唯一 thread ID，执行后清理 checkpoint；单条运行仍创建正常的 Langfuse Dataset Run。
- 外部依赖、LangGraph 执行或数据集输入异常转换为稳定评估错误，不中断同批用例；黄金用例可同时声明正常目标和失败时的备用契约。
